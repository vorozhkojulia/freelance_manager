# Freelance Manager

A pinboard-style dashboard for a solo freelancer: pinned projects as sticky notes, a six-week deadline and workload chart, a money receipt, a project base, a timeline and a finance tracker. Sample data is stored in the browser (localStorage).

## Just open it

No install needed. The ready-to-run site is in `docs/`:

- on GitHub Pages: https://vorozhkojulia.github.io/freelance_manager/
- on your computer: double-click `docs/index.html`

## Edit the code (optional)

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # rebuilds docs/ — commit it to update the live site
```
